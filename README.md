# Сводный реестр заказов: исходники и проверка

Открыть инструмент: двойной щелчок по `registry.html`, затем «Открыть демо-данные» или загрузить файлы из `data/`.

- `TZ.md`: ТЗ v3 с критериями приёмки и историей правок
- `gen_testdata.py`: генератор синтетических таблиц с засеянными дефектами и ключа ответов (`data/answer_key.json`)
- `registry.js`: логика без DOM; её проверяет тест и её же встраивает сборка
- `test.js`: приёмка по 13 критериям: `node test.js`
- `mutate.sh`: проверка самого теста, ломает правила по одному: `bash mutate.sh`
- `ui_test.js`: дымовой тест страницы в jsdom: `npm i jsdom@24.1.3 && node ui_test.js`
- `chrome_test.py`: проверка в Chrome через Playwright: загрузка файлов кнопками, демо, телефон, скриншоты
- `build.py`, `template.html`: сборка `registry.html`
- `data/*.csv`: демо-файлы
